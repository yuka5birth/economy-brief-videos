# 献立リールのルール（全工程共通）

すべての担当がこのファイルを全文読む。

## 1. 何を作るか

- 毎朝9:00にInstagram（@kyou_no_yuugohan）へ投稿する「きょうの夕ごはん」リール（縦型1080×1920・約60秒・ナレーション＋BGM）と投稿文。
- 見る人：毎日の夕食づくりを担う人（主に主婦）。朝に動画を見て、夕方の買い物で使う。
- テーマは固定：**家族4人分（大人2人・子ども2人を想定）・一汁二菜＋ごはん・食材費の合計1000円以内**。
- 料理は誰も試作しない。だからこそ、分量・時間は必ず複数の信頼できるレシピで確かめる（4章）。

## 2. 献立の決め方

- 構成：主菜1・副菜1・汁物1・ごはん（2合＝お茶碗約4杯分）。
- 予算：合計1000円以内。**目標は950円以下**（店や地域で値段がぶれるため）。予算の多くを主菜に回す（目安：主菜500〜650円、副菜80〜150円、汁物40〜100円、ごはん約170円）。
- 旬：その月に旬の野菜・魚を優先する。値上がりしている食材（農水省の価格見通しで「平年を上回る」とされたもの）は量を控えるか避ける。
- 作りやすさ：平日におかず30分前後で作れる。家にある基本の調味料（しょうゆ・みそ・砂糖・みりん・酒・塩・油・ごま油・顆粒だし・鶏ガラスープの素・めんつゆ・マヨネーズ・ケチャップ）で作れる。特別な道具は使わない（鍋・フライパン・電子レンジで足りる）。
- 子ども：辛いもの（豆板醤・唐辛子など）は使わないか「お好みで」にとどめる。骨の多い魚は避ける。
- かぶらない工夫（投稿記録で確かめる）：
  - 同じ主菜は30日以内に出さない。
  - 主菜の主材料（鶏もも／鶏むね／豚こま・豚バラ／ひき肉／魚／卵・豆腐・厚揚げ）は、前日・前々日と同じにしない。
  - 同じ副菜・汁物は7日以内に出さない。
- 料理名は、一般的で検索しても見つかる名前にする（「〇〇の照り煮」「〇〇のごま和え」など）。

## 3. 価格の調べ方と書き方

- 使った分だけ按分して計算する（大根1本のうち1/2本を使うなら1/2本分）。調味料（2章の基本の調味料）は含めない。ただし、すりごま大さじ5のように量が多い・高いものは含める。
- 10円単位に四捨五入する。分からない価格は高めに見積もる。
- 調べる順番（その日に検索して最新を使う）：
  1. 肉・卵：農林水産省「食品価格動向調査（食肉・鶏卵）」の最新月（鶏もも・豚ロース・牛・卵の全国平均）。むね肉・豚こまなど調査にない部位は、近い部位との比率から推定し「推定」と書く。
  2. 米：最新のコメ平均価格（5kgあたり、ニュースで報じられる全国平均）。2合＝300g で計算。
  3. 野菜：農林水産省「野菜の生育状況及び価格見通し」（今月、平年より高いか安いか）と、一般的な店頭価格の目安。
  4. 魚・豆腐・その他：一般的な店頭価格の目安。
- menu.json に、食材ごとの数量・金額・根拠（出典名と日付、または「目安」「推定」）を書く。
- 動画と投稿文には「※価格は全国平均などをもとにした目安です（調味料は含みません）」を必ず入れる。

## 4. レシピの照らし合わせ

- 各料理について、**2か所以上**の信頼できるレシピで分量・時間・火加減を確かめる。信頼の順番：
  1. 自治体・大学・公的機関の資料（食育レシピなど）
  2. 食品メーカーの公式サイト（キッコーマン、味の素、ミツカン、マルコメなど）
  3. 大手レシピサイト（DELISH KITCHEN、macaroni、クラシル、白ごはん.com など）
  4. 投稿型サイト（クックパッドなど）は補助だけ。これだけを根拠にしない
- 参考レシピが「何人分」かを必ず確かめ、4人分に換算する。少なすぎ・多すぎにならないよう、4人分の資料があればそれを優先する。
- 加熱時間・レンジのワット数と時間は、参考レシピの範囲内にする。レビューで「足りなかった」等の声があれば反映する。
- **文章・写真は写さない。** 分量と手順の要点だけを確かめ、手順は自分の言葉で書き直す。参考ページのURLは recipe_check.md に残す（投稿には出さない）。
- 食の安全：
  - 肉・魚・卵を使う料理は、火が通ったかの見極め（「中まで白くなっていればOK」「竹串がすっと通ればOK」など）を必ず書く。
  - 生の肉・魚、半熟卵、はちみつ（1歳未満NG）は使わない。
  - 作り置き・お弁当向けの保存のすすめは書かない。

## 6. 画面の文字とナレーション

- 画面の文字は短く。料理名はできるだけ一般的な表記。
- ナレーションは読み間違いを防ぐため、次のように書く：
  - 数字は漢字かかなで（九百三十円、二合、三十分）。算用数字は使わない。
  - 「一汁二菜」→「いちじゅうにさい」、「鶏もも肉」「鶏むね肉」→「とりもも肉」「とりむね肉」。
  - 読みが不安な語は `python3 -c "import pyopenjtalk;print(pyopenjtalk.g2p('語', kana=True))"` で確かめ、おかしければ、かなで書く。
- 1シーンのナレーションは1〜2文。

## 8. 見送り

次のときは無理に作らず、投稿記録に `見送り` と理由を書いてユーザーに知らせる。
- 予算内（1000円以内）で献立が組めない（値上がりが大きいなど）。
- レシピ照合で、どの料理も2か所以上の根拠が見つからないまま差し戻しの上限に達した。
- 最終チェックの差し戻しが上限（合計2回）に達した。
