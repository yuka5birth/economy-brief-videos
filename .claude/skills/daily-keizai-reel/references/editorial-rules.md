# 編集ルール（全エージェント共通）

## 1. 誰に、何を届けるか

- 視聴者：一般の会社員。通勤電車（音なし）と朝の支度中（音だけ）で見る。
- 届けるもの：会社員が仕事の場で「押さえておいたほうがいい」経済ニュース。会議・商談・職場の雑談で話題になる情報。
- 暮らしへの影響（家計・節約・生活費）の切り口は使わない。
- 投稿者の見方・解釈は入れない。フラットな立場で事実を伝える。
- 1日1本。60秒。

## 2. 収集範囲

| 分野 | 例 |
|---|---|
| 景気・金融政策 | 日銀・FRBの決定、GDP・雇用統計・物価などの重要指標 |
| 通商・政策 | 関税、規制、大型の経済対策、税制 |
| 企業 | 大型の買収・合併、経営トップの交代、業界再編、注目企業の決算 |
| 産業 | AI、半導体、自動車、エネルギーなどの大きな動き |
| 市場 | 株価・為替・金利が大きく動いたときのみ（目安：日経平均・ダウ・ナスダック±2%以上、ドル円±1円以上、または節目の更新） |

対象期間：前日の朝6時（日本時間）から当日の朝まで、およそ24時間以内に新しく出た事実。

情報源の優先順位：
1. 一次情報：政府・中央銀行・USTR・企業の公式発表、統計
2. 主要報道：日本経済新聞、NHK、共同通信、時事通信、ロイター、ブルームバーグ、WSJ、FT、AP
3. その他の報道・まとめサイトは、1か2で裏付けが取れた場合だけ使う

## 3. 1本の選び方（25点満点）

各候補を5つの基準で1〜5点（5が最高）で採点する。

1. 重要度：主要メディアが大きく扱っているか（新聞1面級＝5）
2. 話題性：職場や取引先との会話で話題に上りそうか
3. 影響の広さ：多くの業界・企業に関係するか（日本企業への関係を重視）
4. 新しさ：24時間以内に出た新しい事実か
5. 続きがあるか：今後の発表・決定が控えているか

最高点の候補を選ぶ。同点なら「重要度」が高い方、それも同じなら「影響の広さ」が高い方。

## 4. 重複のルール

- 投稿記録（Googleスプレッドシート）の過去の投稿と同じテーマは扱わない。
- 例外として「続報」で扱えるのは、前回から次のような大きな変化があったときだけ。
  - 検討中・方針段階だったことが正式に決定・発表・発動された
  - 数字が事前の報道や見通しと大きく違う（例：日本の税率が15%以内の見方に反して15%を超えた）
  - 対象が変わった（例：日本が対象から外れた、新しい業界が加わった）
  - 市場が大きく反応した（2章の「市場」の目安を超えた）
- 続報にしないもの：同じ内容の報道の繰り返し、関係者のコメントだけ、新しい事実のない記事。
- 続報の場合：つかみのkickerを「続報｜〜」とし、冒頭で前回の内容を1文で振り返り、新しく分かったことだけを伝える。
- 判定は、テーマ・キーワード・主な事実の3列を見て行う。迷ったら「重複」と判定して別の候補を選ぶ。

## 5. 事実の扱い

- 公開日時を確認できない記事は使わない（過去に、日付のない記事のせいで4か月前のニュースを今週のものと取り違えた）。
- 数字は2つ以上の独立した情報源で一致を確認する。一次情報が1つあれば、それで足りる。
- 事実と見通しを書き分ける。まだ決まっていないことは「〜の方針」「〜との見方」「〜と報じられている」と書く。
- 誰が言ったかを示す：「米政府が発表」「ロイターが報道」「市場では〜との見方」。
- 取引時間中の数字は「一時」「取引時間中」と明記する。終値と混同しない。
- 日付は日本時間で書く。米国の出来事は「米国時間24日」のように明記する。

## 6. フラットな表現

使わない言葉（評価・予想・感情）：
逆風、追い風、懸念、好材料、悪材料、朗報、衝撃、激震、暴落（公式な用語でない限り）、必見、ヤバい、〜すべき、チャンス、危機（引用でない限り）、〜するだろう、〜しそうだ

言い換えの例：
- 「輸出株に逆風」→「輸出企業の採算に影響する可能性があると報じられている」または数字だけを示す
- 「懸念が広がった」→「株価が下落した」（事実）＋「〜を理由に挙げる声がある（〇〇報道）」

- 見方が分かれる政策・政治の話は、両方の立場を並べる。
- 予想はしない。今後については「いつ、何が決まるか」という予定だけを伝える。
- 投資の勧めはしない。

## 7. 60秒の構成

つかみ → 何が起きたか → 背景 → 影響（業界・企業・日本）→ 今後の予定 → 押さえておきたいポイント → 締め

| シーン | 秒数の目安 | 使うシーン型 |
|---|---|---|
| つかみ | 4 | hook |
| 何が起きたか | 8〜10 | text / grid / table |
| 背景 | 8〜10 | timeline / text |
| 影響 | 9〜10 | bars / table / grid / text |
| （任意）市場の反応 | 7〜8 | table |
| 今後の予定 | 7〜8 | points / timeline |
| 押さえておきたいポイント | 6〜7 | summary |
| 締め | 5 | outro |

合計はちょうど60秒。章（hook・outro以外）は5〜6個。

- 影響の章は、報道で名前が挙がっている業界・企業・数字だけを書く。
- 「押さえておきたいポイント」は、会話でそのまま使える2〜3行の要点。
- 締めの文言は固定：「明日も、最新のニュースをお届けします。」「毎朝、いちばん重要な経済ニュースを1本。」「フォローして、見逃さないでください。」

## 8. 見る場面への配慮

- 音なしでも分かる：ナレーションの内容は、すべて画面の文字でも読めること。
- 音だけでも分かる：ナレーションだけで話が通じること。「この図を見てください」は使わない。
- 最初の1コマ（hook）で、何が起きたかと数字1つが分かること。
- 専門用語は言い換えるか、かっこで補う。例：「通商法301条（不公正な貿易への対抗措置を定めた法律）」

## 9. ナレーション原稿の書き方

- 読み上げソフトが誤読しやすい語はかなで書く：日本→「にほん」、米国→「アメリカ」、%→「パーセント」、英字略語→カタカナ（PCE→ピーシーイー、USTR→アメリカ通商代表部、AI→エーアイ）、「1,100円超」→「千百円超」。
- 1文は短く。句点「。」で文を区切る（文の間が自動で詰められる）。
- 目安：1秒あたり6〜7文字（かな換算）。各シーンの秒数から0.45秒を引いた長さに収める。
- 画面の文字と違う事実をナレーションで足さない。ナレーションは画面の要約。

## 10. 投稿文（キャプション）

- 1行目：【今日の経済ニュース】＋見出し
- 3〜5行の要点（✅で始める。絵文字はこれと最後の🔖だけ）
- 「毎朝、いちばん重要な経済ニュースを1本お届けします。フォロー＆保存で見逃さないで🔖」
- 出典：「出典：〇〇、〇〇」
- ハッシュタグは3〜5個（Instagramの上限は5個。6個以上だと反映されないため、絶対に5個を超えない）：#経済ニュース を必ず入れ、残りはテーマ固有のタグ（例：#関税 #日銀 #半導体）。#ビジネスニュース #会社員 は枠が余ったときだけ
