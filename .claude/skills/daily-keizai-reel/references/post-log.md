# 投稿記録（Googleスプレッドシート）

- ファイル名：経済ニュースリール 投稿記録
- スプレッドシートID：`1Y3GSoRvbH_xEaLbZUQVdotP6cflNNREdtROphPPz3jI`
- URL：https://docs.google.com/spreadsheets/d/1Y3GSoRvbH_xEaLbZUQVdotP6cflNNREdtROphPPz3jI/edit
- タブ名：`投稿記録`
- 使うコネクタ：Google Sheets（読み：`get_values`、追記：`append_values`、更新：`update_values`）

## 列

| 列 | 見出し | 書き方 |
|---|---|---|
| A | 投稿日 | `2026-11-25`（日本時間の投稿予定日） |
| B | 種類 | `新規` または `続報` |
| C | テーマ | 1行で。例：米国の新関税・第2弾（過剰生産を理由に16か国・地域へ上乗せの方針） |
| D | キーワード（重複判定用） | ` / ` 区切りで4〜6個。固有名詞・制度名・数字 |
| E | 主な事実・数字 | 動画で伝えた主要な事実。続報判定の基準になるので数字は必ず書く |
| F | 続報元の投稿日 | 続報のときだけ、元の投稿日 |
| G | 選定スコア（25点満点） | 例：`22（重要5/話題4/広さ5/新しさ4/続き4）` |
| H | 選定理由 | 1〜2文。重複判定の結果も書く |
| I | 出典 | 主な情報源の名前 |
| J | ファクトチェック | `PASS（n項目）` または差し戻し回数を含めて記録 |
| K | 動画ファイル | 出力ファイル名（.mp4） |
| L | ステータス | `制作中` / `制作済` / `予約済` / `投稿済` / `投稿エラー` / `取消` / `見送り` |
| M | 投稿URL | 予約時は `Buffer予約 <post id>`、投稿後は InstagramのURL |

## 使い方

- 読む：`get_values` で `'投稿記録'!A:M`。直近60日分を重複判定に使う。
- 追記：制作完了後に `append_values`、range は `'投稿記録'!A1`。日付は文字列 `2026-11-25` のまま送ってよい。
- ステータスの「予約済」は daily-keizai-reel が、「投稿済／投稿エラー／取消」は keizai-reel-post-check が書く。
- 見送った日（ニュースが少ない、重複しか無いなど）も `見送り` で1行残し、理由をH列に書く。
